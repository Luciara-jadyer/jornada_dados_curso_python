# Jornada de Dados — Projeto em Python

## Sobre o projeto

Projeto desenvolvido durante a Imersão Profissional Jornada de Dados,
com foco na aplicação prática de conceitos de Dados e Python.

## Objetivo

Desenvolver uma solução de dados utilizando as etapas trabalhadas
durante a jornada, desde a preparação e transformação dos dados
até sua utilização para análise.

## Tecnologias utilizadas

- Python
- SQL
- dbt
- Git/GitHub
- Data Lake
- Agentes de IA

## O que foi desenvolvido

- Extração e preparação de dados
- Transformação e modelagem
- Estruturação de dados
- Construção de pipelines
- Aplicação de SQL
- Desenvolvimento de soluções com Python
- Aplicações de Inteligência Artificial

## Aprendizados

A jornada permitiu desenvolver uma visão mais completa do ciclo
de dados, desde a ingestão e transformação até a utilização dos
dados para geração de valor.
